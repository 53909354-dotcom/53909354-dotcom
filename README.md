## 📌 关于我

- 陕西明垚环能科技有限公司负责人。公司 2020 年成立，2026 年从传统建筑行业转型能源行业。
- 主营：电厂 / 煤矿钢结构与设备防腐、电厂设备维保与技术改造（不含汽轮机及高压设备）、环保工程。
- 团队 20 人（不含施工队）。走小而专的敏捷路线，不做冗余管理。

## 🎯 在做的事

- **客户深耕**：以陕西能源为样板，12 个月内拓展 2-3 家同量级客户。
- **业务窄化**，只做两件新增业务：
  1. 防腐保温工程产品化 —— 自有天元涂料（交大研发重防腐涂料）+ 施工一体
  2. 设备状态监测 + 轻资节能改造 —— 不碰重资产垫资
- **组织目标**：员工共享公司发展成果，用项目核算和超额利润分享落地。

## 💪 优势

| 领域 | 说明 |
| --- | --- |
| 成本控制 | 自有施工队 + 自有涂料，相对传统维保单位能显著降本 |
| 技术资产 | 天元重防腐涂料，交大研发 |
| 资质 | 环保工程专业承包二级、机电工程施工总承包二级、防水防腐保温二级 |
